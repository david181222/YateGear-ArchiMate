YateGear

API generada desde el modelo ArchiMate: 5 contexto(s) en un solo programa, con los datos en memoria (se pierden al detenerla). Las rutas GET se abren aquí mismo y devuelven JSON. Las POST reciben un JSON: se envían con el pruebas.http de cada contexto (en pruebas/<Proyecto>/, con REST Client de VS Code o con Visual Studio) o con PowerShell, como dice el paso a paso del README del generador.

  • /swagger: la documentación de la API (Swagger), para ver cada endpoint con su contrato y probarlo; el documento OpenAPI está en /openapi/v1.json.
  • /contextos: los contextos que levantó el programa.
  • /eventos-entre-contextos: los eventos que pasaron por el bus entre contextos y los errores de sus suscriptores.
